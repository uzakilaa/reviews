# ⭐ Отзывы клиентов

Страница отзывов, которая обновляется сама: клиент заполняет Google Форму, вы ставите «да» в столбце «Одобрено», и отзыв появляется на сайте.

**🔗 Страница:** https://uzakilaa.github.io/reviews/

## Как это работает
1. Ответы Google Формы попадают в Google Таблицу.
2. Таблица опубликована в интернете в формате CSV.
3. `script.js` загружает CSV, оставляет только одобренные строки и рисует карточки.

## Стек
- HTML, CSS (Grid, адаптив)
- Vanilla JavaScript: `fetch`, собственный CSV-парсер, безопасный вывод через `textContent`

## Настройка
Укажите ссылки на форму и опубликованную таблицу в `config.js`.
